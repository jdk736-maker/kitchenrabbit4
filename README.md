# kitchenrabbit4

Android-App für das persönliche Kochbuch.

## APK automatisch mit GitHub bauen

1. Alle Dateien dieses Projekts in dein GitHub-Repository `kitchenrabbit4` hochladen.
2. GitHub öffnet automatisch den Tab **Actions**.
3. Workflow **Build kitchenrabbit4 APK** öffnen.
4. Nach erfolgreichem Lauf unter **Artifacts** `kitchenrabbit4-apk` herunterladen.
5. ZIP entpacken → `kitchenrabbit4.apk` auf dem Android-Smartphone öffnen und installieren.

Die APK enthält:
- Kochbuch-Oberfläche
- Rezept-URL-Import über strukturierte Recipe-Daten
- automatische Auswahl von zwei passenden Weinen
- CSV/XLS/XLSX-Weinimport (XLS/XLSX benötigt Internet für das Tabellenmodul)
